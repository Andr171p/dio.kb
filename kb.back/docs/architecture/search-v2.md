# Архитектура поискового движка DIOS KB

## Режимы работы

| Режим                              | Механика                                                                           | Особенности               | Применение                                      |
|------------------------------------|------------------------------------------------------------------------------------|---------------------------|-------------------------------------------------|
| `Suggestions` — быстрый поиск      | Поиск по вводу: названия статей, разделов, точные совпадения                       | Без embedding-запросов    | Хедер DIOS, навигация по KB, command palette    |
| `Full Search` — гибридный поиск    | BM25 + dense retrieval, объединение результатов, группировка фрагментов по статьям | Reranking (в будущем)     | Страница поиска DIOS KB, контекст для RAG       |
 | `AI answers` / `RAG` — ответ от AI | Agentic/Naive RAG, надстройка над `Full Search`                                    | MCP/Tool Calling + память | Страница поиска DIOS KB, ассистент портала DIOS |
